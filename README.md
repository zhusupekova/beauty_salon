# beauty_salon
BeautyCRM — веб-сайт  для управления салоном красоты, разработанное в рамках лабораторной работы. Система автоматизирует управление записями клиентов, расписанием мастеров, финансовым учетом и аналитикой. Реализована на HTML, CSS и JavaScript с хранением данных в localStorage. Интерфейс выполнен в розовой тематике, подходящей для салона. Отчет описывает реализованные функции, их соответствие лабораторным требованиям и включает подписи для скриншотов, демонстрирующих работу системы.<img width="468" height="140" alt="image"
