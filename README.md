# BeautyCRM

Веб-приложение для управления салоном красоты. Проект автоматизирует записи клиентов, расписание мастеров, финансовый учет и базовую аналитику.

## Возможности

- управление клиентскими записями;
- расписание мастеров;
- учет услуг и оплат;
- аналитика по работе салона;
- хранение демо-данных в `localStorage`;
- адаптированный визуальный стиль для beauty-сферы.

## Стек

- HTML
- CSS
- JavaScript
- localStorage

## Запуск

Откройте файл `pink/pink.html` в браузере.
